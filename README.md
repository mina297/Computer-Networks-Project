# Enterprise Network Design & Implementation
### CSC230 — Computer Networks | Misr International University

## Project Overview
A full enterprise network simulation designed and implemented 
using Cisco Packet Tracer as part of the Computer Networks 
course (CSC230) at Misr International University, under the 
supervision of Dr. Yasmin Alkady.

The network connects a main campus with 4 buildings, a remote 
branch site, and a wireless home network — all through a 
central ISP — with complete routing, security, and management 
features configured end-to-end.

## What's Implemented
- VLSM addressing scheme from 10.0.0.0/8 across 13 subnets
- VLAN segmentation, 802.1Q trunking & EtherChannel (LACP)
- Inter-VLAN routing via SVIs and Router-on-a-Stick
- OSPFv2 & EIGRP with bidirectional route redistribution
- DHCP server with address pools and relay agents
- Dynamic NAT with PAT & Static NAT
- Site-to-Site IPsec VPN (AES-256)
- NTP, Syslog, DNS, Email (SMTP/POP3) & Web server
- Wireless network with WPA2/AES security
- Full end-to-end connectivity verification
